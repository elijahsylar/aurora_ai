# Aurora canvas study

A static page describing a program that runs pretrained language models on a 100 by 100 text canvas, what was logged between 7 March and 14 June 2026, and the limits of that data.

- `index.html`: the page.
- `queries.sql`: every SQL query behind the page's numbers.
- `figures/`: three canvas images, selected by the rule stated on the page.

The program's source code and the database are private. The page quotes the prompts and rules needed to read the figures.
