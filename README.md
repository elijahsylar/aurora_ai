# Aurora: pilot report and audit

A static page reporting the pilot of Aurora, a system that gives language models a 100 by 100 text canvas, a small command vocabulary and no reward signal. The pilot ran from March to June 2026. The page describes the system as it ran, the pilot dataset, an audit of that dataset and of earlier claims about it, and the current protocol.

Author: Elijah Sylar Camp.

## Files

- `index.html`: the report.
- `queries.sql`: the read-only SQL queries behind the numbers on the page, each labeled with the audit section that produced it.
- `figures/`: three example canvas images, selected by the rule stated on the page, and two charts.

## Code and data

The code and the dataset are private. Both are available on request for review.
